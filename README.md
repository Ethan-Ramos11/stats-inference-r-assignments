# Probability and Statistical Inference Assignments

This repository contains a series of R programming assignments completed for a Probability and Statistical Inference course. The assignments demonstrate practical implementation of statistical concepts using R programming. This is an ongoing course, and more assignments will be added as they are completed. All assignments were completed by me as part of the course requirements, implementing concepts from the textbook and demonstrating practical application of statistical methods.

## Course Information

- **Course**: Probability and Statistical Inference (In Progress)
- **Textbook**: [Probability, Statistics and Data: A Fresh Approach Using R](https://probstatsdata.com/discreterandomvariables.html)
- **Textbook Authors**: Darrin Speegle and Bryan Clair

## Skills Demonstrated

These assignments showcase proficiency in:

- R programming and statistical computing
- Data visualization using R's plotting capabilities
- Statistical analysis and inference
- Probability theory implementation
- Data manipulation and cleaning
- Statistical hypothesis testing
- Confidence interval construction
- Model fitting and evaluation

## Technical Requirements

To run these assignments, you'll need:

- R programming language (latest version recommended)
- RStudio (recommended IDE)
- Basic R packages:
  - stats (base R)
  - graphics (base R)
  - ggplot2 (for advanced visualizations)
  - dplyr (for data manipulation)

## Usage

Each assignment file can be run independently in R. The files contain:

- Detailed comments explaining statistical concepts
- Implementation of theoretical concepts
- Data analysis workflows
- Visualization code
- Statistical tests and their interpretations
